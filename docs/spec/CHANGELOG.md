## Rev.3.4 — 2026-05-25（リリース整合・実装照合）

- 参照実装 **`tk2-rv64-virt`** の `make TK2=1 qemu` で M5（`ABAB` + `[M5] COMPLETE`）を確認。
- Phase 1〜4 を完了とし、Phase 4 は **公式 `tkernel_2` リンク + M5** で充足と記録。
- 実装で確定した追補（HLNG は `ra` 保存、`mstatus` MPIE、`TK2=1` ビルド）を [`TK2-RV64-SPEC-v3.4-RELEASE.md`](TK2-RV64-SPEC-v3.4-RELEASE.md) に整理。
- **v3.2 / v3.3 は全文維持**（v3.4 は差し替えではない）。

## Rev.3.3 — 2026-05-25（設計補足・誤解防止）

- 正本は **Rev.3.2 を維持**（「Rev.3.2 は技術的に正しい」と明記）。
- 第三者が誤解しやすい点を短文化: **構成 A/B 差分**、**trap 入口の x2（mscratch）**、**BSS 8 バイトアライメント**。
- ファイル `TK2-RV64-SPEC-v3.3.md` は **全文仕様の置き換えではない**（実装は v3.2 + v3.3 参照）。

## Rev.3.2 — 2026-05-24（技術評価・実装検証版・実装正本）

- `switch_context`: 割込即時有効化レースを避け **mret/sret** 遷移を規範化。
- `trap_entry`: スタック **280B → 288B**（RISC-V 16B アライン）。
- `mtimecmp`: **符号付き差分**でラップアラウンド耐性。
- キャストマクロ名を `TK_CAST_PTR_TO_REGUINT` 形式に統一。
- CHANGELOG を正本巻末付録 B に統合。

詳細は `TK2-RV64-SPEC-v3.2.md` 先頭の改訂履歴および付録 B。

## Rev.3.1 — 2026-05-23（技術査読・設計改訂版）

### ドキュメント

- 単一プレーンテキストから **Markdown 正本 + README + CHANGELOG** 構成へ再編。
- §0（文書管理・互換性定義）を新設。
- 付録 B（Rev.2.2 査読結果）、付録 C（既知制限）を追加。

### 致命・重大修正（実装ブロッカー）

| ID | 箇所 | 問題 | 改訂 |
|----|------|------|------|
| C-01 | §5.1.2 | `switch_context` の **save が +8 オフセットずれ**、restore と不一致 | save を `0*8` 基準に統一。構造体レイアウト表を追加 |
| C-02 | §3.4 | コメント終端が `/` のみで **コンパイル不能** | 正しい `*/` に修正 |
| C-03 | §3.4 | `typedef const void CVP` — ポインタ欠落 | `typedef const void *CVP` |
| C-04 | §5.2.2 | `sbi_set_timer` で `a0` を二重定義 | SBI 0.2 TIME 呼び出し規約に準拠した単一 `a0` 束縛へ修正 |
| C-05 | §4.2 / §6.3 | メモリマップ（最大 2GB）とリンカ **128M の矛盾** | メモリプロファイル P0/P1 を導入し用途を分離 |
| C-06 | §5.2.1 | `mtimecmp` 遅延時に `current_cmp + Δ` が `mtime` より過去になり得る | `max(mtime, mtimecmp) + Δ` 方式を規範化 |
| C-07 | §5.3.1 | Rev.2.2 記載の trap 入口 **MIE 抑止**がコードに未反映 | `csrci mstatus, 8` を保存シーケンス前に明記 |
| C-08 | 付録 A | 「バイナリ 100% 互換」が LP64 移植と矛盾 | **ソース/構造体 ABI 互換**に用語を限定 |

### 設計・記述の改善

- `TASK_CTX_RV64` のフィールドオフセット表とサイズ（128 B）を明示。
- `TRAP_CTX_RV64` のスロット割当（x1, x2, x3…x31, CSR）を図示。
- FPU 拡張時のコンテキストサイズ式: `128 + sizeof(CTX_RV64_FPU)`（16B アライン）を §5.1.3 に追記。
- §3.5 に `TK_CAST_PTR_TO_REGUINT` 等のキャストマクロ例を追加。
- §6.2 `boot.S` の `.Lhalt` 節のコメント欠落を修正。
- §4.2 の誤字「動的動的」→「動的」。
- Rev.2.1 欠落について版履歴を整理（2.0 → 2.2 は内部ドラフト、3.1 で正式系列化）。

### 互換性

- Rev.2.2 からの **API 方針（INT/UINT 32bit 維持）は不変**。
- アセンブリ実装は C-01 により **必ず再ビルド** が必要（バイナリ互換なし）。
